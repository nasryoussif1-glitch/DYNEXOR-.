DYNEXOR - Website Starter
========================

طريقة التشغيل:
1) فك ضغط الملف.
2) افتح مجلد DYNEXOR في Visual Studio Code.
3) افتح index.html في المتصفح أو استخدم إضافة Live Server.

دخول لوحة الإدارة:
- اضغط "لوحة الإدارة" في أعلى الموقع.
- كلمة المرور التجريبية: DYNEXOR@2026
- لتغييرها: افتح script.js وعدّل قيمة ADMIN_PASSWORD.

ملاحظات مهمة:
- طلبات التواصل تُحفظ في localStorage على نفس المتصفح والجهاز فقط.
- هذه نسخة Front-end تجريبية؛ كلمة المرور ليست حماية حقيقية ويمكن كشفها من ملفات المتصفح.
- قبل نشر الموقع واستقبال طلبات حقيقية، اربط تسجيل الدخول بخادم Backend وقاعدة بيانات، واستخدم تشفير كلمات المرور وجلسات آمنة.
